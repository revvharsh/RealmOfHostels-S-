# Realm of Hostels

Unified student and admin hostel-management portal.

## Run Locally

Prerequisites: Node.js and pnpm.

```bash
pnpm install
pnpm dev
```

The development server runs on `http://localhost:3000`.

## Portals

- Student: enter any student email with password `codersrealm`.
- Admin: username `realmofhostels`, password `codersrealm`.

The student and admin portals share tickets and notices during the same app session.
